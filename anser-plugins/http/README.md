# 渠道网络策略

默认只允许可路由的公网 HTTP(S) 地址。DNS 返回的每个地址都需要通过检查，连接时使用已检查的 DNS 结果。HTTP 重定向和系统代理环境变量关闭。内网部署可将确切的域名或 IP 加入 `ANSER_OUTBOUND_ALLOW_HOSTS`，多个值用逗号分隔。`ANSER_ALLOW_PRIVATE_NETWORK=1` 允许全局访问内网，适合部署者明确控制全部目标的环境。

渠道的 `proxy` 可指定 HTTP 或 HTTPS 代理。目标主机和代理主机都要显式列入 `ANSER_OUTBOUND_ALLOW_HOSTS`。代理可以自行解析目标域名，部署者应仅配置可信代理。为凭据保密，自建服务通常使用 HTTPS。

请求超时为 20 秒。响应体上限为 256 KiB。默认重试分类如下。

| 情况 | 分类 |
| --- | --- |
| DNS 暂时不可用、网络故障、超时 | 可重试 |
| HTTP 408、429 或 5xx | 可重试 |
| HTTP 401、403 | 凭据或权限错误 |
| 其他 HTTP 非 2xx 状态 | 不可重试 |
| 地址、代理或参数不符合配置 | 不可重试 |
| HTTP 2xx 但响应内容无法解析 | 可重试 |
